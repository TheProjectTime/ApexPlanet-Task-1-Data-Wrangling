# ApexPlanet Task 1 - Data Immersion & Wrangling

## Project Overview

This project was completed as part of my ApexPlanet internship.

The objective of this task is to understand, assess,
clean, transform, and prepare a sales dataset for
further analysis.

## Dataset

The dataset contains sales transaction information
including customer, product, date, quantity, price,
and sales information.

## Objectives

- Understand the dataset
- Create a data dictionary
- Identify data quality issues
- Handle missing values
- Check duplicate records
- Standardize data formats
- Detect outliers
- Perform feature engineering
- Create an analysis-ready dataset

## Tools Used

- Python
- Pandas
- NumPy
- Microsoft Excel
- Visual Studio Code
- GitHub
